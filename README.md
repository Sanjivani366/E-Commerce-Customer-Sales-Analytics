# E-Commerce Customer Sales Analytics

## About
This project analyzes e-commerce customer data using Python, Pandas, and Exploratory Data Analysis (EDA).

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- EDA

## Project Analysis
- Customer analysis
- Gender-wise spending analysis
- City and state-wise spending
- Customer tier analysis
- Monthly sales trends
- Top 10 customers
- Age vs spending analysis
- Customer spending segmentation

## Project Workflow
Data Cleaning → Feature Engineering → EDA → Data Analysis → Visualization → Business Insights

## Dataset
The project uses an e-commerce customer sales dataset containing customer details, orders, and total spending.

## Visualizations
The project includes charts for monthly spending, gender spending, customer tiers, top cities, age vs spending, and customer segmentation.
